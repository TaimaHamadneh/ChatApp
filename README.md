# 💬 Local ChatGPT‑style Chat

A simple chat application built with **Streamlit** that generates mock replies **without any external LLM or API**. Perfect for learning Streamlit's `st.chat_message`, `st.chat_input`, and session state management.

## How to run
```bash
pip install streamlit
streamlit run chat_app.py
```
Check this: https://chatgpt-test-app.streamlit.app/
